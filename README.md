🤖 Thara AI 1.2 (macOS Edition)
Thara AI is a personal voice assistant built with Python and powered by Ollama. It can understand voice commands, open applications, search the web, play music, capture screenshots, and assist you with everyday tasks using natural voice interaction.
Version: 1.2
Platform: macOS
Language: Python

🚀 Installation
Clone the repository
git clone https://github.com/YOUR_USERNAME/Thara-AI-1.2.git
Go to the project folder
cd Thara-AI-1.2
Install dependencies
pip install -r requirements.txt
Run Thara AI
python main.py

⚙️ How It Works
Launch Thara AI.
The startup animation will appear.
Thara activates the microphone.
Say "Thara" to wake the assistant.
Thara replies "Yes Boss".
Speak your command.
Thara processes and executes your request.
